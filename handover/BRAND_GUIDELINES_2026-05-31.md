## 2. コピー規約（全媒体共通）

### 2-1. 基本4ルール

1. **自社代表 = 「テンイチ（代表）」**
2. **効率比較は抽象化**（具体棟数より「数十棟」等の曖昧表現を好む）
3. **因果接続詞必須**（論理的接続を重視）
4. **jargon 回避**

### 2-2. 必ず使う訴求軸

| 訴求 | 表現 |
|---|---|
| 手数料 | **手数料 8%**（業界相場の半額）— 必ず含める |
| 業界比較 | 業界中央値 20% vs 自社 8% = 半額 |
| チーム | **Airbnb スーパーホスト認定を多数獲得している運営者を中心としたチーム** |
| カバレッジ | **全国対応**（NOT 「全国7拠点」） |
| 受賞 | BEST OF SAUNA STAY 2026 受賞（プレスリリース付き） |
| 切替 | 最短2週間で切替可能 |
| ローンチオファー | 先着10名で乗り換え初期費用無料 |

### 2-3. 絶対NG表現リスト

| ❌ NG | 理由 | ✅ 置き換え |
|---|---|---|
| 「業界でもっともシンプルな料金体系」 | 業界比較の断言を避ける | 「シンプルな料金体系」 |
| 「全国7拠点で対応」 | 数字固定で拡大時の矛盾 | 「全国対応」 |
| 「1人で100物件以上」 | 品質不安連想 | 「1物件あたり運営コスト業界平均の半分以下」or「スーパーホスト多数認定チーム」 |
| 「成果型でお約束」 | 景表法違反リスク | 削除 |
| 「手数料 8% だけ」 | 月額固定（¥5,000-10,000）あるため嘘 | 「業界相場の半額・手数料 8%」 |
| 「代表が直接対応」 | 営業チーム対応の実態と乖離 | 「創業者の想い」「ビジョンと実績」 |
| 「日本初の AI 民泊代行」 | AI ハイプ感がブランドと不一致 | 「業界の常識を変える」 |
| 「最低契約期間 6ヶ月」のような付帯情報 | 不要と判断すれば削除 | （文脈次第） |
| 「その結果〜」が文脈に合わない場合 | 因果接続詞の論理性重視 | 適切な接続詞に置換 |
| 「と思っています」等の弱い表現 | 言い切り表現を好む | 断言→自虐のコントラスト |
| 「業界の数十棟」等の具体数字 | 業界比較は曖昧に | 「数十棟」程度の曖昧表現 |

### 2-4. 数字表記

- 通貨: **円・万円表記に統一**（K表記禁止・¥500K等NG）
- 円: 小数点以下不要（Math.round 使用）
- 一覧番号: 「1つめ/2つめ」等の数字表記（ひらがな「ひとつめ」NG）

### 2-5. CTA文言

| ✅ OK | 🚫 NG |
|---|---|
| 「無料で面談を予約する」 | 「気になれば話してもいいかな」（弱い） |
| 「専門家に無料相談する」 | 「話してもいいかな」 |
| 「運用に関するご相談はこちら」（/switch header）| — |
| 「物件診断レポート無料作成」 | 「24時間以内に担当者からご連絡」（弱い）|

### 2-6. 受賞表現

- 受賞・実績は **バッジ＋プレスリリースリンク形式** で視覚的に強調
- ⚠️ 受賞バナーは **外部リンク禁止**・物件カード外の独立 callout に配置（離脱防止）
- スーパーホスト認定は「自慢」でなく **「運営力が生きてくる」程度の控えめな表現**

## 3. 媒体別トーン・AI言及ポリシー

### 3-1. AI 言及ルール

| チャネル | AI 言及 | 理由 |
|---|---|---|
| **X** | ✅ 出す | AI起業家像・勢いのある起業家感を演出 |
| **LinkedIn** | ✅ 出す | ビジネスインフルエンサー像 |
| **note** | 🚫 完全禁止 | けんすう寄り・落ち着いた経営者トーン |
| **HP / LP** | 🚫 完全禁止 | 「AI化」→「仕組み化」「AI自動」→「日次自動」 |
| **PR TIMES** | 🚫 控える | 客観事実重視 |

### 3-2. 媒体別ペルソナ

| 媒体 | ペルソナ | トーン |
|---|---|---|
| **X**（@tenichiliu） | 田端型・1軸フォーカス（民泊×AI） | 控えめ・実装ログ・現場ベース。「現場で動いてる人」感 |
| **X**（@jirosan） | ジロー本人・現場運用ノウハウ | 経営者目線ではなく現場視点・手動投稿 |
| **X**（@ss_unei_chan） | 架空運用マネージャー | 日常業務・オーナー対応エピソード |
| **note** | 経営者・けんすう/田端/馬田風 | AI感ゼロ・落ち着いた経営者トーン・物語性重視 |
| **LinkedIn** | ビジネスインフルエンサー | AI中心で事業を回す起業家トーン |
| **HP/LP** | プロダクト訴求 | オーナー視点・控えめな信頼ベース |

### 3-3. note 特有ルール

- **対象オーディエンス**: 地方のおじさん（専門用語・カタカナビジネス語が通じない層）
- 固有名詞（Airbnb スーパーホスト等）はそのままOK
- 一般的でないカタカナ語NG：「再ポジショニング」→「見せ方を変える」
- ADR等の業界略語は初出時に日本語注記必須（例：平均宿泊単価）
- 営業はAI自動化から除外（「AIで自動化」と書くのはWebマーケ出稿・経理などバックオフィス業務のみ）

### 3-4. LinkedIn 特有ルール

- 核メッセージ1本を設計してから、そこに向けて各セクションの役割を明確にする構造設計
- 冒頭の複数引用より1つに絞る構成
- 「ひとつめ/ふたつめ」等のひらがな数字より「1つめ/2つめ」
- 「Airbnb未掲載でも大丈夫です」は LP の注意書きコピーとして使用中 → 投稿CTAには使わない
- 反論コメントには **知的で実体験ベース** の返信（テンプレ返信は弱い）

### 3-5. X 特有ルール

- 段落余白で区切り、article風 divider（`---`）は使わない
- メタナレ（「これから〜書きます型」）も避ける
- 短文リズム優先
- 長文B（4000字）は確定スタイル: ❶❷❸記号・本文絵文字ゼロ・glossary最小・自虐(笑)・CTAブランド名
- スレッドだけでなく長文単一投稿も混ぜる
- 絵文字は投稿ごとに変える（全部同じパターンは飽きる）
- 各 X 投稿画像に SEKAI STAY のロゴヘッダーを必ず入れる（透けた白ヘッダー + 左寄せロゴ）

## 6. 画像・ビジュアル

### 6-1. 画像生成エンジン

| 用途 | エンジン |
|---|---|
| 日本語テキスト含む画像 | **GPT Image 1**（デフォルト） |
| 文字なしビジュアル | Gemini / Imagen 3（フォールバック） |

### 6-2. X / note 画像

- 画像内テキスト: **日本語**
- LinkedIn 用の日本語テキスト混入防止ルールは X/note には適用しない
- ブランドヘッダー: 透けた白ヘッダー + 左寄せ SEKAI STAY ロゴ
- 画像格納: **Google Drive**

### 6-3. AI 動画生成（要慎重）

- オーナー向け B2B は信頼ベース
- AI 動画の「作り物感」はブランド毀損リスク
- 実写素材＋AI補助のハイブリッドが安全
- Seedance 2.0 は「1本試作・人間承認後」のみ採用
- 自動化パイプライン構築は NG
- 物件紹介は **実写優先**

### 6-4. 創業者ページ画像

- 画像は背景に配置
- モバイルでは劉の画像を明神に合わせて下辺揃え・若干小さく
- 人物画像の下辺を他の画像と揃えてサイズ調整

## 7. 内容軸・コンテンツ戦略

### 7-1. オーガニックコンテンツ 5本柱

1. オーナー成功事例
2. **おすすめ民泊家具・アメニティ**（NOT 「代行業者選定ノウハウ」）
3. OTA 運用テクニック
4. 法務制度（民泊新法・条例・税務）
5. 業界トレンド（市場規模・競合動向）

### 7-2. 家具投資哲学（コンテンツの裏側）

- **印象を決めるシンボル家具**（ダイニングテーブル・ソファ・額縁）には投資
- **印象に影響しない家具**（洗濯機・冷蔵庫・照明・ラグ・食器・アメニティ）はコスパ重視
- 造作家具は高見え・機能性向上の有効手段（一枚板テーブル・ビルトインソファ・二段ベッド）
- TV → プロジェクター + ロールスクリーンで非日常・空間活用・コスト削減

### 7-3. 業界比較表現

- 競合の管理能力を「数十件」と控えめに表現
- 自社は「2倍以上効率がいい」と自然に示す
- 「数学的厳密さ」より「読みやすさ」優先（「ポイント」より「%」）
