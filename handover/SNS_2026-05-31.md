## 1. LinkedIn 自動投稿（`projects/sekaichi-linkedin/`）

### 1-1. アーキテクチャ

```
Claude Sonnet 4.6 が週次プラン生成 → Google Sheets 投入
  ↓
Vercel Cron が毎日朝 plan を読み込み
  ↓
Unsplash + Sharp で 1200×627px ブランド画像合成
  ↓
平日 23:00 JST に LinkedIn API v2 で投稿
  ↓
毎日 22:00 JST にコメント監視 → AI 返信生成 → Discord 承認 → 投稿
```

### 1-2. Cron スケジュール（`vercel.json`）

| パス | スケジュール | 用途 |
|---|---|---|
| `/api/cron/daily-post` | `0 23 * * 0-4`（平日 23:00 JST） | 投稿実行 |
| `/api/cron/daily-tasks` | 毎日 22:00 JST | コメント返信・コネクション承認 |
| `/api/cron/collect-engagement` | 毎日 14:00 JST | エンゲージメント分析 |
| `/api/cron/token-check` | 毎週月曜 09:00 JST | トークン期限チェック |

### 1-3. 主要ファイル

| ファイル | 役割 |
|---|---|
| `lib/ai/content-generator.js` | Claude コンテンツ生成 |
| `lib/linkedin/client.js` | LinkedIn API v2 投稿 |
| `lib/images/generator.js` | Unsplash + Sharp 画像生成 |
| `scripts/linkedin-browser-tasks.js` | Playwright（コネクション承認・DM転送） |
| `data/posts.json` | 事前生成済み投稿メタデータ |

### 1-4. 環境変数

```
LINKEDIN_ACCESS_TOKEN
LINKEDIN_PERSON_URN
LINKEDIN_API_VERSION=202602
ANTHROPIC_API_KEY
CLAUDE_MODEL=claude-sonnet-4-6
GOOGLE_SPREADSHEET_ID
GOOGLE_REFRESH_TOKEN
UNSPLASH_ACCESS_KEY
SLACK_WEBHOOK_URL
SLACK_DM_WEBHOOK_URL
DISCORD_WEBHOOK_URL
```

### 1-5. 既知の課題

- 🟡 セッション期限管理は GitHub Actions (Playwright) で1年前提
- 🟡 期限切れ時は `npm run linkedin:setup` で再設定必須
- 🟢 返信承認フロー（Discord ボタン承認制・案A）実装中

### 2-3. 戦略（3軸・月7本目標）

| 軸 | 内容 | 月本数 |
|---|---|---|
| **A. 経営者自己開示** | 創業時意思決定・失敗・葛藤 | 月2本 |
| **B. 業界構造分析** | コスト構造・価格構造・労働構造分解 | 月3本 |
| **C. オーナー成功物語** | 5年運用の実話・再生物語 | 月2本 |

### 2-4. トーン規約（重要）

- 🚫 **AI / 効率化 言及ゼロ**
- ✅ けんすう note 寄り
- ✅ 地方オーナー向け（横文字最小化）
- 📏 2500-5500字
- ✅ 固有名詞（Airbnb スーパーホスト等）はそのままOK
- 🚫 「再ポジショニング」等の一般的でないカタカナ語NG → 「見せ方を変える」等に言い換え
- 🚫 ADR等の業界略語は初出時に日本語注記必須（例：平均宿泊単価）

### 2-5. 運用フロー

```
Google Sheets「note Pipeline」タブで管理
  ↓ Status=Reviewed
cron が処理
  ↓
DRY_RUN=true → 下書き保存
DRY_RUN=false → 公開
```
