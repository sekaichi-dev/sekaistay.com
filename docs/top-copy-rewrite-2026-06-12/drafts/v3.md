# バージョン3:「オーナーストーリー型」

## 狙い・フック解説

/switch で実証済みの「松本さん（56歳・仮名）」式モデルケース手法を、トップページの背骨に昇格させる。1人のオーナー「Kさん（モデルケース・数字は当社管理物件の実数）」の物語——稼働58%で伸び悩んでいた野尻湖の貸別荘が、1年で稼働82%・月商134万円になるまで——を第1章〜第3章の連載構造でページに貫通させ、読者が「数字の羅列」ではなく「自分の未来の追体験」としてサービスを理解できるようにする。最初に掴むのは乗り換え検討オーナーの「うちの物件、本当はもっと稼げるんじゃないか」という燻った疑念。同時に、物語の途中に「Kさんと違って、物件をまだ持っていないあなたへ」という明示的な分岐点（第2.5章）を設け、新規オーナーが置き去りにならない二車線構造にした。/switch から借りたのは「同一人物がページ内で再登場し数字がブレない」一貫性と損失額の計算提示。変えたのは、悩み提起の道具だったモデルケースを「ページ全体の語り部」に拡張した点と、創作人物のプロフィールと実数の出典を明示して透明性をコピー自体の訴求力に変えた点。
