# バージョン1:「数字直球型」

## 狙い・フック解説

民泊オーナーの最大の不満は「手数料がいくらで、何をしてくれて、結果いくら残るのかが曖昧」なこと。だからこのバージョンは抽象コピーを極限まで削り、ファーストビューから最終CTAまで全セクション見出しに数字を置いた「数字のショーケース」として設計した。ヒーローは料金そのもの（8%＋¥10,000）を見出しにして固定費を見出し内で同時開示（NG1回避）、直後に「月商100万円なら9万円 vs 20万円」の計算式を見出し化して/switchの損失額提示パターンを借用。一方、数字の羅列は冷たくなるため、全数字に「オーナーにとってこの数字は何を意味するか」を1行で添えて体温を保つ。乗り換えオーナーには手数料差の計算、新規オーナーには「初月稼働68%」という0→1の数字を入口にして両方を受ける。掴む感情は「自分の物件の数字、ちゃんと見たことあるか？」という当事者意識。

# バージョン2:「損失喚起型」

## 狙い・フック解説

このバージョンは「読者自身に電卓を叩かせる」一点に賭ける。/switch で実証済みの損失試算パターン（手数料差 × 時間軸）をヒーロー直下に前倒しし、ページを読み進めるほど「差額が毎月発生している」という計算事実が積み上がる構成にした。感情を煽るのではなく、**月商 × 手数料率 × 12ヶ月**という誰でも検算できる式だけで語る（NG8厳守：恐怖訴求なし・全て手数料差の計算ベース・試算条件は都度明記）。乗り換えオーナーには「過去に払った額」、新規オーナーには「最初から払いすぎない」と同じ式を未来向きに翻訳して両方を受ける。/switch から借りたのは試算カードと✗/✓比較とSTEP構造。変えたのは、損失提示を1セクションに閉じず、料金→事例→乗り換えフローの各所で「この差は計算するとこうなる」と繰り返し着地させる点。

# バージョン4:「時間解放・丸投げ型」

## 狙い・フック解説

現行サイトの「民泊運営は、もう丸投げでいい。」を捨てずに、本気で深掘りする。民泊オーナーの本当のペインは手数料の前に「時間」——深夜の英語メッセージ、昼休みのレビュー返信、週末のOTA管理画面。まず「いま奪われている1週間」を具体的なシーンで見せて自分ごと化させ、「オーナーがやること／SEKAI STAYがやること」の業務リスト対比で丸投げの中身を可視化し、最後に「丸投げ＝放置ではなく、リアルタイムダッシュボードで全部見える丸投げ」へ反転させてオチをつける。この「見えるから任せられる」軸は、乗り換えオーナーの「いまの代行、結局自分が働いてる」不満と、新規オーナーの「本業と両立できるのか」不安の両方に同じ答えとして効く。/switch からは ✗/✓ 対比・損失額の計算式・「入力3分・無料・営業連絡なし」のmicrocopyを借り、構成は「悩み→流れ→実績」テンプレを捨てて「時間の喪失→業務の移管→可視化→数字」の物語順に再発明した。

このバージョンは「営業せずに、質問させる」構成。乗り換えオーナーの最大の感情は「今の代行、なんとなく不満だけど、何が悪いのか言語化できない」という靄（もや）であり、新規オーナーの最大の感情は「何を基準に会社を選べばいいか分からない」という不安。この2つは実は同じ欠落——**評価基準を持っていない**——から来ている。そこで、ページの背骨を「代行会社に聞くべき10の質問」にする。乗り換えオーナーには「今の会社に聞いてみてください」という挑戦状として、新規オーナーには「契約前チェックリスト」としてそのまま機能する二重設計。各質問にSEKAI STAYが即答で答えを並べることで、「質問に即答できる会社」という透明性そのものが最大の差別化証明になる。/switchから借りたのは具体数字での損失計算と✗/✓対比の精神。変えたのは語りの主導権——こちらが語るのではなく、オーナー自身に「聞かせる」ことで、比較検討の土俵を当社の強い場所（透明性・開示スピード）に設定する。質問はすべて業界慣行への問いであり、特定他社への言及・品質批判は一切しない。

# バージョン7:「事例ファースト型」

## 狙い・フック解説

サービス説明を一切せず、ヒーローの1行目から実在物件の数字を見せる。「稼働率58%→82%」という Before/After は、伸び悩む乗り換えオーナーには「自分の物件との差」として、新規オーナーには「民泊はここまで回るのか」という相場観として、説明ゼロで刺さる。構成は帰納的に組む——①事例3本（乗り換え×2＋新規立ち上げ×1）→②「そこで何をしたか」を6本柱へ逆引き→③「では、あなたの物件なら？」と診断CTAへ着地。/switch から借りたのは Before/After 対比と損失額の計算提示。変えたのは順番で、/switch が「不満→解決策→事例」と演繹で下るのに対し、トップは「事例→手法→あなた」と帰納で上がる。成果は過去実績としてのみ語り、「あなたの物件でどうなるかは診断で確かめる」という誠実な接続でNG2（確約）を構造的に回避する。

# バージョン8:「新規・乗り換え分岐型」

## 狙い・フック解説

トップページの本質は「2種類の来訪者を、それぞれ正しい説得ラインに3秒で振り分けること」。このバージョンはその役割を隠さず、むしろ見出しで宣言する。ヒーローは「民泊の悩みは、だいたい2つに分かれます」と来訪者自身に自己診断させ、直後に2レーンへ分岐。各レーンは/switchの口語フック（乗り換え=「20%も払ってるのに、この対応？」）と、新規向けに新造した鏡像フック（「何から始めればいいか、分からない」）から書き起こし、レーン内で悩み→解決→数字→CTAを完結させる。単なる2枚のカードにしないため、分岐直前に「あなたはどっち？」のチェックリストを置き、読者が自分の台詞を見つけて進む構造にした。そして後半で「どちらの道でも、着く場所は同じ」と合流——料金・ダッシュボード・運営チームが共通であることを、分岐構成だからこそ際立つ「合流の演出」として使う。/switchから借りたのは✗/✓対比・損失額の時間軸提示・STEP構造。変えたのは、それらを乗り換えレーンに閉じ込めず、新規レーンには「不安の時系列を潰すSTEP」という別の武器を与えたこと。
